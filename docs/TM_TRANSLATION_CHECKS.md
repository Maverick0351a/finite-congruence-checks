# Turing-machine translation checks

Two programs can both stop after the same number of steps and still leave
different answers on their tapes. This experiment compares the complete
configuration: **state, head position, halting status, and every nonzero cell**.

The maintained [Python port](../scripts/tm_port.py) is compared with a native
Lean executable using the exact machine definitions from a pinned OpenAI math
source. Five small Lean lemmas describe the source's step behavior. The Python
comparison is bounded execution evidence; the lemmas prove statements about
the Lean definition.

The [Turing atlas panel](TM_ATLAS.md) connects four exact pairs to separate
halting-time, tape, and head-position claims, with inspectable traces and
qualified lemma links. Its [retrieval exercise](TM_ATLAS_EVALUATION.md) tests
whether an agent selects evidence at that same level of precision.

**Recorded result:** the [build and execution receipt](../evidence/tm-port-v1/summary.json)
reports agreement on all **2,857 snapshots**, zero disagreements, **34** rejected
malformed inputs, and **7** detected output corruptions. The five Lean lemmas
passed kernel replay; their axiom reports contain only `propext` and `Quot.sound`.
All **45 Python tests** passed, including independent review's evidence-tampering
controls. The recorded run used Ubuntu-Shannon WSL; offline replay also passed
on Windows. AI-assisted review is recorded separately from these executed checks.

The supplied `openai-math-audit-bundle.tar.gz` has SHA-256
`4ec4960fcac8c6901a68cfa66c4b3690d80831c1528f80793c05cafff578005d`.
Its original `oai-tm/tm.py` has SHA-256
`be5d7fae033590a2105773605aa8a513192b0e8e254856b0e74028195ed872f9`.
The [independent rerun record](../evidence/tm-original-review.json) preserves
the observed bugs and distinctions:

- With fuel zero, the original halting helper takes a step but reports zero
  steps. A missing instruction can even return an already halted configuration
  alongside a false halting flag.
- Negative natural-number fields and an invalid movement code can enter the
  original Python representation. Lean's types exclude them.
- Replacing an explicit final instruction with a missing instruction removes
  its write and movement. Agreement on halting time does not restore those effects.

An earlier local repaired package had already corrected the fuel boundary and
basic domain checks. This maintained version builds on those repairs, copies
and freezes mutable containers, and adds comparison with compiled Lean.
Original uploads and historical local validation records are preserved.

## Two ways to stop

The head is the cell the machine currently reads. Blank cells contain zero.
Here both machines start with an empty tape and a head at position zero:

```text
                     one step
No instruction:      [0] ──────────> [0]   halted; head stays here
                      ^              ^

Write 1, stay, halt:  [0] ──────────> [1]   halted; head stays here
                      ^              ^
```

The first transition changes only the state to a halting sentinel. The second
executes a rule before reaching a declared halting state. Their numeric final
state can be identical while the roles of that state differ.

For a configuration `c = (state, head, tape)`, the extracted step rule is:

| Situation | Next configuration |
|:--|:--|
| Already halted | `c` |
| Active, instruction missing | `(sentinel, head, tape)` |
| Active, instruction `(q, a, d)` present | `(q, head + d - 1, tape[head := a])` |

Here `d = 0, 1, 2` means left, stay, right. An explicit rule writes at the
**old** head position, then moves. Halting is checked before taking a step.

## The bounded helper contract

`halts(machine, input, fuel)` observes times `0` through `fuel` and takes at most
`fuel` transitions. If it returns `(flag, n, configuration)`, the configuration
must equal `run(machine, input, n)`. A true flag identifies the first observed
halt; a false flag means no halt was observed within the bound and `n = fuel`.
It is not a conclusion about eventual nonhalting.

Fuel zero returns the initial configuration. An initially halted machine is
reported at time zero. Negative head positions are valid: the tape is indexed
by integers, while states, symbols, counts, and step limits are natural numbers.

Python uses plain integers for these fields, excluding booleans and floats.
Movement is restricted to `0..2`. Machine tables, halting-state lists, and tape
maps are copied into immutable snapshots. This closes the possibility that a
caller changes a list after it has been validated.

Lean's **types** and its **predicates** are separate. The port accepts finite
machine tuples whose fields have the right types even when `WellFormed` is
false, and natural-valued input words even when `ValidInput` is false. Short
tables and extra entries are representable. The flat instruction index is
preserved, including above-alphabet indexing for such inputs. These cases are
included deliberately; silently enforcing stronger restrictions would change
the interface being compared.

## Exact source and proof boundary

The source is [OpenAI math commit 1581d4c, machine definitions at lines 10–66](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/lean/ComparatorChallenges/NavierStokesAlternating.lean#L10-L66).
The full file SHA-256 is
`0166c40c57bd9eb6ede9e25bda09650b859c81c0d801de9faa3875f195e003fc`.
The [source manifest](../lean/tm/source/manifest.json) records the exact byte
span and hashes. [check_source.py](../lean/tm/check_source.py) verifies the
complete snapshot, unchanged extracted definitions, and approved import and
namespace wrapper. The source's Apache-2.0 license is retained.

The separate project pins Lean **4.34.1** and Mathlib commit
`d13f23b723b8a846827a245b89c10fc7d3f11612`. It compiles only the machine fragment
with two narrower imports. The complete upstream file is retained as provenance;
the surrounding PDE development is outside this check.

[MachineChecks.lean](../lean/tm/MachineChecks.lean) proves five source statements:
halted configurations are fixed; missing instructions update only the state;
present instructions have the stated update; they write the old head cell;
and they preserve all other cells. The runner builds these declarations, captures
their fully qualified axiom reports, and runs Lean's bundled `leanchecker`.
These proofs do not establish a general Python/Lean equivalence or a theorem
about arbitrary compiled machine instructions.

## Reproduce the comparison

Python 3.10 or newer suffices for the port, tests, and offline evidence replay.
A fresh native comparison also requires the pinned Lean toolchain and dependency
cache. From the repository root:

```sh
python -m unittest discover -s scripts -p 'test_tm*.py' -v
python lean/tm/check_source.py
cd lean/tm
lake exe cache get Mathlib.Logic.Function.Iterate Mathlib.Data.Int.Basic
cd ../..
python scripts/run_tm_checks.py run --out runs/tm-checks
python scripts/run_tm_checks.py replay --out runs/tm-checks
```

To check the committed run without installing Lean:

```sh
python scripts/run_tm_checks.py replay --out evidence/tm-port-v1
```

Choose a new output directory for each run. The runner builds the oracle itself;
it derives the executable path from that project. It saves source hashes,
toolchain and build commands, proof logs, the compressed executable and its hash,
exact inputs, native outputs, full disagreements, and malformed-input probes.
It checks that sources and binary remain unchanged during execution.

The deterministic input set contains **2,857 configuration snapshots**:

| Portion | Snapshots | Coverage |
|:--|--:|:--|
| Named cases | 297 | Fourteen cases, including both halt behaviors, tape erasure, negative positions, initially halted and short-table cases, very large naturals, and six benchmark variants |
| Exhaustive small domain | 1,960 | All 49 complete two-entry tables for one ordinary state and two symbols; each entry missing or one of six rules returning to state 0; two halt-state lists, four input words, and times 0–4 |
| Deterministic sample | 600 | One hundred two-state/two-symbol tuples, including type-valid ill-formed cases, observed at times 0, 1, 2, 3, 7, 16; seed 20261018 |

The oracle emits sorted nonzero tape cells. Starting from a finite word, all
potentially nonzero cells after `n` steps lie in
`[-n, max(n, input_length - 1)]`. This contains the entire support, including
negative positions. The support argument is documented and reviewed; the JSON
adapter and observation loop are not covered by the five source lemmas.

The harness must reject changed state, head, tape, or step outputs, missing and
duplicate records, and malformed JSON. Native decoder probes separately check
negative numbers, booleans, decimal/exponent numbers, malformed rules, and an
out-of-range movement. Python tests exercise the port's domain and fuel contracts.

Offline replay checks retained evidence against the current sources and exact
case generator. It checks the binary archive hash but does not execute that
binary. Hashes establish artifact identity; they are not signatures or protection
against someone replacing an entire evidence set. Native results additionally
depend on the compiler, runtime, dependencies, adapters, and execution environment.
