# Questions and problem reports

For a first run, follow the [README quick start](README.md#quick-start). For the
meaning of a successful check, read the [claim ledger](docs/CLAIMS.md) and
[verification method](METHOD.md). The [evidence guide](docs/EVIDENCE.md) explains
the recorded files and how to reproduce them.

Use a [repository issue](https://github.com/Maverick0351a/finite-congruence-checks/issues/new/choose)
for a reproduction problem, proposed experiment, or question. While the
repository is private, this requires repository access. Include the version or
commit, environment, exact command, and smallest relevant input. Avoid posting
credentials, private datasets, or unrelated personal information in logs.

A negative search result and a failed verification are different outcomes:
the search may find no witness within its stated bound, whereas a verifier
failure means the supplied candidate did not pass its checks. Report the exit
code and the recorded failure reason so the result can be interpreted correctly.

This is a research project maintained on a best-effort basis. There is no
guaranteed response time. Contributions and independent replications are welcome;
see [CONTRIBUTING.md](CONTRIBUTING.md).
